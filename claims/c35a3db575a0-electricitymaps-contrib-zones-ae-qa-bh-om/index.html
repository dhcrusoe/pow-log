Environmental Sustainability

So electricitymaps reports a carbon intensity for these five grids that reflects their actual fuel mix instead of a generic worst-case assumption.

What is actually checkedelectricitymaps-contrib zones AE, QA, BH, OM and SA had no zone-specific emission-factor override for unclassified 'unknown' production, defaulting to a generic 575/700 gCO2eq/kWh value; PR #8854 (opened 2026-09-11, unmerged as of this claim) adds one per zone, weighting the repo's own IPCC-2014 per-fuel factors by each zone's latest Ember generation mix.

Costs — what this makes worse
None identified. The change only populates a fallback path (the emission factor used when a zone's production is reported as unclassified 'unknown'); it does not change behavior for any zone whose production is already reported by fuel type.
What was done
Read open issue #6003 (electricitymaps/electricitymaps-contrib), which asked for carbon-intensity overrides for UAE, Qatar, Bahrain, Oman and (conditionally) Saudi Arabia and suggested combining Ember production-share data with the project's own per-fuel emission factors. Downloaded Ember's current public Yearly Electricity Data export, extracted each zone's most recent full-year generation mix by fuel, and combined it with electricitymaps' own config/defaults.yaml IPCC-2014 direct and lifecycle factors (gas 370/490, oil 406/650, coal 760/820, zero-carbon sources 0) to compute a mix-weighted 'unknown' override for each zone. Edited the five zone config files to add emissionFactors.direct.unknown / .lifecycle.unknown plus a plain-language disclaimer, matching the existing pattern already used for Bolivia's zone config. Verified beforehand that this specific fix had not already been attempted and rejected (a related but different idea, an exchange-config addition for a different issue, had been rejected by a maintainer, so that direction was abandoned in favor of this one). Opened pull request #8854 against the upstream repository.
Who is better off: Anyone reading electricitymaps' Gulf-region carbon intensity once merged: the site's users, researchers and journalists, who currently see a generic worst-case thermal assumption instead of each grid's real fuel mix (notably UAE's ~23% nuclear share).
